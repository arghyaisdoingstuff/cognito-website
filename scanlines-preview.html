HOW GPU COMPOSITING ELIMINATES LAG:
1. Orbs: Rendered as multi-stop radial gradients without dynamic `filter: blur(80px)`. The texture quad is generated once and shifted via hardware `translate3d` and `scale3d` transforms.
2. Scanlines: Instead of animating `background-position` (which forced full-screen CPU repainting on every frame), we animate `transform: translate3d`. The GPU compositor operates entirely off the main JavaScript and layout threads.
